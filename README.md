Entry for the make.fun bounty **"Warning Label for Humans: One Line, Big Laugh"**.

`main.ts` writes a single-line safety warning label for every human being to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The label is
plain ASCII, exactly one line with no trailing newline, and 145 characters —
inside the 160-character limit.

The entry:

> WARNING: This human skipped the manual, ignored the warnings, asked no questions, and will confidently press the one button labeled DO NOT PRESS.

Run it with:

```sh
node main.ts
```
